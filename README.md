# Site Clube Estrela | Supermercado Araújo

Site responsivo do Clube Estrela para o Supermercado Araújo.

## Estrutura
- `index.html` — página principal
- `css/style.css` — estilos e responsividade
- `js/script.js` — menu, WhatsApp e eventos de interação
- `assets/` — logos e imagens da galeria

## Aplicativo Clube Estrela
Os botões de download direcionam para:
- Google Play
- App Store

## Publicação
Envie o conteúdo deste pacote para a pasta pública da hospedagem, mantendo `index.html`, `css`, `js` e `assets` no mesmo nível.

O site pode ser publicado em hospedagem estática comum, cPanel/public_html, Netlify, Vercel ou serviço equivalente.
